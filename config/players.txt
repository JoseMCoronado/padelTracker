# Club list — the players offered in the club round picker.
#
# One name per line. Blank lines and anything after a '#' are ignored, and
# surrounding spaces are trimmed. Order does not matter: the picker sorts by
# name. A name repeated here (in any casing) counts once.
#
# This file is the single place the club list lives. Both the simulator and the
# court unit read it:
#
#   simulator     picked up on the next launch, no rebuild
#   court unit    baked into the firmware, so it lands on the next flash
#
# The list owns the names in it. Delete a line and that player disappears from
# the picker on the next start. Players added with NEW PLAYER on the
# touchscreen are not in the list and are never removed by it, so this file can
# be edited without worrying about the guests and walk-ups a session collected.
